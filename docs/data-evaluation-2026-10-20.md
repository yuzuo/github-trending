评测时间：2026-10-20 15:51–15:58（北京时间）。
数据来源：23 服务器在线只读 API；关注项目历史样本；本地增长率计算代码。
评测对象：当前系统保存的 GitHub 项目、动态、Agent 分析与自动验证结果。

## 1. 结论

**系统已经能积累项目热度、发现版本变化并触发检查，但目前只能辅助筛选候选项目，尚不能证明哪个工具能稳定完成实际社交平台采集任务。**

主要结论：

1. 11 个关注项目的监测检查仍在更新，验证 worker 心跳正常；存在新版本被发现、自动检查完成的证据。
2. Agent 分析是当前最明显的短板：376 条动态中，199 条分析失败、119 条过期，只有 29 条处于 ready。
3. 自动验证共 22 个任务，19 个通过、3 个执行错误；其中只有 2 个是 Scrapy 本地固定场景功能测试，其余 20 个为源码检查。
4. 目前没有足够的实测证据判断视频号、YouTube、Facebook、Instagram、抖音、TikTok、小红书的字段完整率、真实成功率或每日稳定产量。
5. 优先解决模型服务错误、限流和分析积压，再为与你业务相关的候选项目补充真实采集测评。继续增加源码检查数量无法替代这一步。

### 时间与热度口径

- 当前 `growth_24h` 选择距离最新样本 24–30 小时的基线，实际上是近一天的观测差值，不是严格统一的 24 小时增量。
- 例如 Firecrawl 的 +389 对应约 29.9 小时，不能直接与其他项目约 24 小时窗口公平比较。
- 当前所有七天增长值为空。按本地排序逻辑，缺少增长值时会用总 Star 数参与排序，因此此时默认列表顺序不应解释成“最近七天最火”。
- 动态 `changed_at` 是本系统发现或更新记录的时间，不能解释为原项目首次发布事件的时间。历史 Release 入库也不能算成近期新发布。
- 11 个关注项目返回的历史样本中，相邻观测最大间隔约 6.2–10.2 小时。说明采样并非严格等间隔；这不是持续在线率的证明。

### 内容相关性

动态中发现明显偏离项目功能的内容，例如 MediaCrawler 的 Issue #994 为 Gmail 注册及商业推广内容。应保留原始证据，但在推荐和重要提醒中标记无关内容，避免噪声占用模型分析额度。

部分项目与当前业务匹配较低，例如小说系统、微博采集工具。可以保留观察，但在七个平台的采集选型中不应获得同等优先级。

## 7. 优化优先级与验收

### P0：恢复可持续的数据分析

1. 核查模型服务 HTTP 402 原因，确认恢复后分批重试历史失败，避免对额度错误持续无效调用。
2. 检查 GitHub 凭据是否实际生效、额度分配与调度；关注项目更新优先于大范围发现。
3. 对失败、过期与积压单独显示数量和最老等待时间。不要让“最近一轮成功”掩盖大量历史失败。
4. 将 ValueError 等泛化错误细化成可行动原因，保留资源限制；不通过简单放开所有限制处理失败。

验收：连续观察至少 24 小时，新动态能进入分析、失败原因可定位、积压下降、重点项目按约定周期刷新。具体错误率目标在恢复后依据实际基线设定。

### P1：使分析与你的场景相关

1. 把已明确的业务需求写入项目使用档案：目标平台、标题/描述/作者/点赞数/评论数/媒体地址、每日 100–500 条。
2. 为真实试用项目记录实际版本，不能自动把最新版本当成正在使用版本。
3. 将发布功能、无关推广、普通讨论与采集故障区分。
4. 显示热度统计起止时间；七天样本未就绪时明确提示，避免总 Star 排序被误读。

### P1：建立与你需求一致的实测

优先顺序按当前已有证据和业务相关性确定：

1. 抖音/TikTok：对比 TikTokDownloader 与 Douyin_TikTok_Download_API。
2. 小红书：先测 Spider_XHS，再按需求比较其他候选。
3. Instagram：测试 Instaloader 的目标访问范围和所需字段。
4. 视频号、YouTube、Facebook：当前关注与验证证据不足，补充对应候选及测试。

每个平台先以 20–50 条已知内容建立人工核对样本，再每日 100 条连续运行 3 天，通过后测试 500 条。

至少记录：

- 成功率：成功解析的目标条数 / 有效目标总数。
- 字段完整率：按每个字段单独计算；不存在的原始标题允许标为不适用，不能用生成标题冒充。
- 点赞数、评论数的采集时间与人工核对时间；互动数会随时间变化。
- 重复率、失败重试后恢复率、登录失效次数、人工干预次数。
- 视频/图片地址即时可访问率与延迟复查结果；同时保留原始作品地址。
- 每天实际采集量、耗时和资源开销。

在真实采集前仍需明确：关键词/固定作者/指定链接的入口，账号访问范围，以及只保存媒体地址还是下载文件。这些选择会改变测试口径。
